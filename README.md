One-line 3 AM hardware-wallet excuse entry for the make.fun bounty
[The 3 AM Excuse](https://make.fun/bounty/u-hazel-walrus-38-4764-the-3-am-excuse-c1017878).

`main.py` (Python 3 stdlib only) writes a single hardware-wallet
excuse to `/output/entry.txt` — 87 characters, one line, UTF-8, no
trailing newline.

## Files

- `main.py` — the entry (stdlib-only copier)
- `README.md` — this file
- `LICENSE` — MIT

## Run

```sh
python3 -P -s main.py
```
